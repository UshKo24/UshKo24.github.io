minigolf/index.html        — страница «Безумной лунки» (мини-гольф), тема golf
arsenal/index.html         — страница «Арсенала Удачи» (сундуки с оружием), тема arsenal
kotovasiya/index.html      — страница «Котовасии» (кот в доме, 7 концовок), тема kot
mazomus/index.html         — секретная страница «Мазомус Рана», тема mazomus. На главной карточка скрыта (hidden):
                             её открывает еле видное яйцо в правом нижнем углу раздела «Игры» (запоминается в localStorage)
budka/index.html           — секретная страница «Будки», тема budka. Карточка скрыта: открывается, если набрать на главной «хрю»
                             (на телефоне — три быстрых тапа по «?» в карточке «Скоро»)
dota3/index.html           — секретная страница «Доты 3», тема dota. Только скачивание (Windows), без веб-версии.
                             Карточка скрыта: открывается 5 быстрыми кликами по логотипу-маяку (запоминается в localStorage)
music/index.html           — раздел «Музыка»: плеер со всеми треками из игр. Треки — mp3 в music/,
                             список — массив TRACKS в начале скрипта страницы (добавить трек = одна строка)
engine/godot-<версия>/      — общий движок Godot для всех игр (godot.wasm, godot.js) — браузер качает его один раз
games/<игра>/              — пакет игры (index.pck) и страница запуска (index.html), без своей копии движка
tools/add_web_build.py     — подключает веб-экспорт Godot к общему движку
img/                       — обложки и скриншоты (полный размер и уменьшенные *_s.webp)
downloads/                 — версии для Windows и Android
style.css, theme.js        — оформление и темы игр
updates.js                 — лента обновлений на главной (новые записи — сверху)
catalog.js                 — фильтр игр по жанрам и меткам + вывод ленты обновлений
fonts/                     — шрифты (Oswald, Rubik — SIL OFL)

Темы:
- Без темы сайт нейтральный: тёмный фон, янтарные кнопки, справа плывёт мозаика из кадров всех игр.
- У каждой игры своя тема: html[data-theme="<игра>"] в style.css — только цвета, фон и декор в .hero.
  Шрифты одинаковые во всех темах (Rubik), новые темы шрифт не меняют.
- Клик по карточке на главной плавно перекрашивает сайт в стиль игры. «Все игры» и логотип — обратно.
- Страница игры всегда в своей теме (<html data-theme="...">).

Как добавить новую игру:
1. В Godot: Проект → Экспорт → Web, выключить «Thread Support», экспортировать в любую папку,
   потом: python3 tools/add_web_build.py <папка экспорта> <имя-игры> [цвет фона загрузки]
   Скрипт возьмёт только index.pck и иконки, а движок подключит общий (новая версия Godot добавится сама).
   Пакет сохраняется как games/<имя>/<имя>-<хеш>.pck — у каждой сборки новое имя, поэтому браузер
   не подсунет старую версию из кэша. После обновления поправь путь пакета в MayakPreload.startIdle
   на странице игры и поменяй ?v= у frame.src.
2. Скопировать папку turniket/ в <имя-игры>/ и поменять тексты, картинки, data-theme, MayakTheme.remember и путь в frame.src
3. Добавить карточку на главную (index.html, блок class="games") с data-game="<тема>" и
   data-shots="кадр1 кадр2 ..." — имена картинок из img/ без _s.webp. Эти кадры сами попадут в мозаику.
4. Добавить тему в style.css (html[data-theme="<тема>"] { ... }) и её цвет в theme.js (COLORS).

«Девятый вал» временно убран с сайта (коммит «Убрать Девятый вал…»). Его тема devyatyi в style.css,

Жанры и метки:
- У карточки на главной: data-genre="<жанр>" и data-tags="<метки через пробел>". Списки жанров и меток — в начале catalog.js.
- Жанры: idle roguelike strategy td horror puzzle chess tanks shooter arcade sim manage story casual sport sandbox
- Метки: duo bots friends short long endings browser pc phone 3d pixel wip fav (fresh ставится сама по дате в updates.js)
- Жанр или метка без открытых игр не показывается. Секретные игры учитываются только после того, как их открыли.

Лента обновлений:
- При каждом обновлении игры добавить запись СВЕРХУ в updates.js:
  { d: "ГГГГ-ММ-ДД", g: "<тема игры или site>", v: "версия", n: "название обновления", i: ["что добавили", "что исправили"] }
- Записи секретных игр видны только тем, кто открыл их карточку. После правки updates.js поменять ?v= у него в index.html.
